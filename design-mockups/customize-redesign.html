Concept I

The Wizard

A guided, step-by-step flow for first-timers. One decision per screen, big readable previews, and an escape hatch to Advanced for power users. Answers the core complaint — "not cluttered" — by showing only one question at a time.

Design notes

  • Wider: 820px vs the current ~440px, so two-column theme cards with real previews fit without scrolling.
  • Preview images: each theme card carries a live CSS mini-render of its actual look, not an abstract sketch.
  • One question per step removes clutter entirely — Theme → Mode → Size → Cards, each a full clean screen.
  • Advanced escape hatch in the footer jumps power users straight to the full cockpit, skipping the wizard.
  • Honest tradeoff: a wizard adds clicks for repeat users. Best paired with "remember I've done this" so it only guides on first open.
Concept II

Sidebar + Canvas

A permanent left rail of sections. Click once to switch context; the canvas shows the relevant controls at full width. Skins are grouped Light / Dark with visible swatches. Card shapes each get a CSS preview tile — you can see the silhouette before picking.

Design notes

  • Wider: 860px — skins lay out 3-column with color swatches visible without opening the panel.
  • Light / Dark grouping: skins are split into two labelled groups so users don't pick a dark skin when they want light mode.
  • Sidebar navigation removes the cramped horizontal tab bar (9 tabs in ~440px) in favor of a persistent left rail — always visible, no scrolling.
  • The Canvas area adapts — clicking Skins shows the swatch grid, clicking Cards shows shape tiles, etc.
Concept III

Accordion + Shape Gallery

One vertical scroll. Each setting group is a collapsible row showing its current value at a glance; open one to reveal its controls. The Cards section is the star — a full visual gallery where every silhouette is drawn on a miniature card mock, per surface.

Design notes

  • Visual shape gallery is the headline: every silhouette rendered on a mock card so users see exactly what they're picking — no more reading "notched / deckle / aperture" text labels blind.
  • Collapsed rows show the current value (skin name, accent hex, font) so the whole config is scannable at a glance without opening anything.
  • Dark/Light toggle lives in the header, always reachable.
  • Single scroll — no horizontal tab bar. Works well on narrow panel widths (your 42vw).
  • Trade-off: only one section open at a time keeps it tidy, but power users comparing two groups must click back and forth.
