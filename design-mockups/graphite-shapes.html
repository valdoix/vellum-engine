VELLUM II — Graphite Shapes

Same DOM · swap shape only

Eight new card silhouettes for the Graphite chrome, built to the real shape contract: geometry only — radius, border, clip-path, mask, or reserved padding plus a single pseudo-element detail. No new markup, no color or type baked in. Each row below is the identical card DOM; only the shape class differs. Distinct from all 24 existing shapes — a machined, instrument-panel family.
