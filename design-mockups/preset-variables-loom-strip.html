How the preview works (real, not simulated)

  • Source: spindle.assemble({ blocks, chatId, promptVariables }) runs Lumiverse's full prompt-assembly — resolving {{char}}, history, world-info and your variable choices — and returns the exact system messages the model would receive. It never calls an LLM, so it's free and instant.
  • What's shown: the resolved session-settings block, rendered as a manuscript excerpt. The footer echoes the active dials (POV · tense · stakes) so cause and effect are legible.
  • Debounced: a variable change waits ~800ms, then re-assembles — the same rhythm as the save, so one gesture updates value, preview, and persistence together.
  • Fallback (State B): with no chat open, macros can't resolve, so the preview shows a quiet prompt instead of broken text. Requires the generation permission — which VELLUM already holds.
  • Honest preview: it shows the prompt the model sees, not a fabricated response. For an actual generated sample we'd use generate.quiet(), which costs tokens — offered later as an explicit “generate sample” button if wanted.
