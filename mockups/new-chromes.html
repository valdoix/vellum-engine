VELLUM · New Chrome Mockups

Six chrome concepts, each shown as a floating window with the six customizable surfaces (Present, Bonds, Cast, Beats, Factions, Items). The first three are maximalist / neon / loud / bright (Arcade, Riot, Carnival); the last three are maximalist / fantasy / colorful (Grimoire, Prism, Bestiary). All built to slot into the existing Chrome + Skin + CHROME_SHAPES architecture. Fonts load from Google Fonts, matching how gatsby/sumi already pull display faces on demand.
